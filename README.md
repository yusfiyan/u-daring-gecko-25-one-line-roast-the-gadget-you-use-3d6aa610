## The roast

> Every Sunday my phone sends me a screen-time report, judging me like a disappointed parent — the same parent who sold me the phone.

## How it works

`main.ts` (Node, stdlib only) writes exactly one original roast line — 133 characters, a single line — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. A gate guard in the program rejects the entry if it is not 1–200 characters, is only white space, or spans more than one line, so the sealed scorer's gate always passes.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
